## 3. Visual system (Brand Lock) — from live Desktop/home

**Default surface is LIGHT, not charcoal.** Marketing pages use warm off-white; product UI is light IDE chrome; dark (`#000`) is for contrast sections only.

**Palette (exact)**
| Token | Hex | Use |
|---|---|---|
| Page / ad ground (default) | `#F7F6F5` | Primary static background |
| Ink | `#191919` | Headlines, body |
| Pure black | `#000000` | Primary CTAs, dark sections, high-contrast frames |
| White | `#FFFFFF` | Cards, buttons on dark, product chrome |
| Accent blue | `#317CFF` | Sparse accent only (tags, links, one underline/dot) — also seen as `#337DF4` |
| Vivid blue (rare) | `#2200FF` | Avoid in ads unless matching a specific product moment |
| Muted label | ~`#6B6B6B` | Secondary lines, mono captions |

**Do not** default ads to neon-on-black “AI dark mode.” Dark ads are allowed only as intentional contrast (e.g. one enterprise frame) with white type — not purple gradients.

**Typography**
- Display / UI: clean grotesque sans (`nbInternationalPro` or nearest: Inter / similar). Regular + medium. Tight tracking on big headlines.  
- Labels / technical: mono (`Geist Mono` / `IBM Plex Mono`) — small, all-caps section tags like `STATS`  
- No ornate editorial serifs on v1 statics  

**Logo / mark**
- Cognition/Devin mark: **three black circles in a tight triangle** (compact geometric). Prefer this mark or the word **Devin** / **DEVIN** — do not invent a new logo.  
- Clearspace ≥ mark height. Never recolor to neon, never put on busy photo.  
- Enterprise customer marks on site are grayscale — match that restraint if using logos (only with permission / public proof).  

**Layout for Meta statics (1080×1080 and 1080×1350)**
- Typographic first: one headline, optional one subline, optional mark or DEVIN wordmark  
- Safe zones: keep critical type out of top/bottom ~10%  
- Plenty of `#F7F6F5` empty space  
- Optional: one small `#317CFF` mono tag (e.g. `PRO` / `ENTERPRISE`)  
- Product UI crops only if from real Desktop chrome and still Brand-Lock clean — never fake illegible IDE soup as the hero

## 4. Forbidden (automatic Brand-Lock fail)

- Neon robots / humanoid “AI” mascots / cartoon agents  
- Fake IDE with illegible lorem code as the hero  
- Purple / magenta “AI startup” gradients · cyberpunk glow  
- Defaulting every ad to charcoal/black when the site default is `#F7F6F5`  
- “Replace engineers,” “fire your team,” “AGI coworker”  
- Seat-count pricing on enterprise ads  
- Unnamed “Fortune 500 saved millions” without a cited public proof  
- Busy stock office photography  
- Ornate editorial / magazine styling that fights the product chrome
