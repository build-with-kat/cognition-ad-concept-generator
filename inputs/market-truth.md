## 2. Buyers & workflows with strongest evidence

### A. Self-serve / power developers (Pro/Max) — strong category language

**Workflow (OBS-backed category):** Cloud / background / async agent = **ticket → PR**, not autocomplete.  
- **OBS:** AI/TLDR — cloud agent “goes off to a fresh remote machine… comes back later with a finished pull request”; “You don’t babysit it. You delegate, walk away, and check the result.” (access 2026-09-15)  
- **OBS:** BuildMVPFast — “You’re a dispatcher”; output = “a branch and a PR, not a suggestion in your editor.”  
- **OBS (X, Trylions):** cloud agent = async GitHub-native coding worker, distinct from IDE agent mode.  
- **OBS (Reddit r/vibecoding):** “Cursor is great when I want tight feedback… Devin is better for handing off well-defined work… bigger issue is context, not model quality.”

**INT for copy:** Lead with category nouns (*async PR*, *ticket → tested PR*, *dispatcher*) before brand lore.

### B. Engineering / platform leads — strong on backlog parallelism + review bottleneck

**Workflows:**  
- Backlog as **parallelism** (migrations, flaky tests, dependency bumps, coverage gaps) — one playbook / many repos.  
- Trust = **review capacity**, not generation volume (*lines that survive review*; *morning batch review*; *finished diff to check*).  
- **OBS (Reddit r/windsurf):** fork is review loop — “Devin hands you a finished diff to check, Claude Code lets you watch and interrupt… I pick by how verifiable the task is.”

### C. Enterprise (VP Eng / CIO / platform / security / procurement) — medium evidence, thin independent Devin diaries

**Workflows (category + vendor-adjacent):** governed fleets; permission controls / isolated sandbox / audit trail / bounded autonomy; measurable modernization — **without invented ROI**.  
- **OBS (X):** permission gates, session replay, “real data instead of demos,” “No lock-in.”  
- **Limitation:** Independent last-90-day Devin customer diaries scarce vs category “async agent” content; enterprise logos in company-context = **CLAIM / re-verify**, not Meta static proof in Marley sample.

### Secondary (weaker core ICP)

Designers / PMs / founders shipping with agents — Replit often wins blank-page. **Do not** lead Meta statics with idea-to-app / “no coding” (wrong ICP for Devin core).
